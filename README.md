# 최저임금은 우리 생활비보다 빨리 올랐을까?

2026 데이터분석 연구발표회 출품작. 2014~2025년 최저임금과 소비자물가지수를 비교하는 Streamlit 웹앱입니다.

## 작은 질문
1. 최저임금과 물가는 각각 몇 % 올랐나?
2. 어느 분야의 물가가 가장 많이 올랐나?
3. 실질 최저임금은 2014년보다 얼마나 늘었나?

## 파일 구성
- `app.py` : 웹앱 코드 (데이터 불러오기 / 사이드바 / 차트 그리기)
- `requirements.txt` : 필요한 라이브러리 (streamlit, pandas, plotly)
- `data/cpi_2014.csv` : 지출목적별 소비자물가지수, 2014년=100으로 바꾼 값
- `data/min_wage.csv` : 연도별 최저임금 시간급과 최저임금지수(2014년=100)
- `data/real_wage.csv` : 실질 최저임금 = 시간급 ÷ 물가 총지수(2014년=100) × 100

## 데이터 출처
- 국가데이터처, 「소비자물가조사」 지출목적별 소비자물가지수(품목포함, 2020=100), 국가통계포털 KOSIS (https://kosis.kr)
- 최저임금위원회, 연도별 최저임금 (https://www.minimumwage.go.kr)

## 전처리
- 두 데이터의 단위와 기준이 달라 모두 2014년=100으로 다시 계산함
- 2015년 주류 및 담배 지수 급등(담뱃값 인상)과 2018년 최저임금 16.4% 인상은 실제 값이므로 지우지 않고 그래프에 표시함
